AutoML Agent - Generated illustration set

All files use a light blue/purple 3D illustration style and a pale background (not transparent).

Recommended web assets: use the .webp versions for smaller downloads.
Use the .png versions when you prefer lossless images.

03-ai-workspace       -> AI Workspace decorative illustration
04-results-analytics  -> Results page / analytics empty state
05-reports            -> Reports page / report empty state
